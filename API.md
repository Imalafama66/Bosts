# API

La documentación interactiva está disponible en `/docs` y `/redoc`.

- `POST /api/auth/register`, `POST /api/auth/login`, `GET /api/me`
- `GET|POST /api/bots`, `PATCH|DELETE /api/bots/{id}`
- `GET|POST /api/contacts`, `PATCH|DELETE /api/contacts/{id}`
- `GET /api/messages`, `POST /api/whatsapp/send`
- `GET /api/stats`, `GET /api/system/status`, `GET /api/health`
